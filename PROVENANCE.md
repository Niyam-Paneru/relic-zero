# Provenance

This repository is the public relay/state core from a private Relic Zero experiment.

## Preserved

- one active capability;
- consume-before-issue ordering;
- token hashing;
- append-only public touches;
- state derivation by replay;
- manual handoff.

## Rewritten for public review

The Three.js renderer, persistence, moderation UI, production secret, analytics, and deployment configuration are not included.

## Claim boundary

The public repository demonstrates the relay semantics. It is not the full interactive application.

The panda, regrettably, contributed no code review.
